Privacy Policy

How request data and telemetry are handled across our content delivery network.

1. Data Collection

Albin CDN operates as a public static asset delivery network. We do not track users, collect personal identifying information (PII), or store cookies on client devices accessing static assets.

2. Server Access Logs

To maintain network performance, prevent abuse, and mitigate Distributed Denial-of-Service (DDoS) attacks, edge servers temporarily capture standard HTTP access logs. These logs include:

  • Anonymized Client IP addresses
  • Requested asset URI paths
  • HTTP User-Agent strings
  • Timestamps and request latency metrics

3. Data Retention

Standard server access logs are retained for a maximum of 30 days solely for security monitoring, debugging, and traffic analysis, after which they are automatically purged.

4. Contact Information

For inquiries regarding privacy practices or network operation, contact albinanthony.tech@gmail.com .
