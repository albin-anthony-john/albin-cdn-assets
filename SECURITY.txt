# Security Policy

## Reporting Security Issues

If you discover a potential security vulnerability or unauthorized asset modification within this CDN repository, please report it responsibly rather than opening a public issue.

### How to Report
Please email security concerns directly to:
* **Email:** `albinanthony.tech@gmail.com`

Include as much detail as possible:
* Type of issue (e.g., unintended exposure, script injection risk)
* Affected file path or URL
* Steps to reproduce the issue

### Policy & Response Time
* **Acknowledgement:** Received reports will be acknowledged within 24 to 48 hours.
* **Resolution:** High-severity vulnerabilities will be patched promptly upon confirmation.
